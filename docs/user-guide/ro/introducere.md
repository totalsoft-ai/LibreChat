# Introducere

Tessa este o platformă inteligentă de conversație bazată pe AI, concepută pentru a oferi utilizatorilor o interfață modernă și intuitivă de chat. Aplicația integrează un orchestrator automat de agenți, funcționalități avansate de căutare documentară și o suită completă de instrumente AI.

Tessa utilizează un sistem de Orchestrator care identifică automat cerința utilizatorului și direcționează solicitarea către agentul specializat potrivit, fără a fi necesară selectarea manuală a asistentului. Toate funcționalitățile disponibile în versiunile anterioare sunt păstrate integral, reunite acum sub o interfață unificată numită “Assistant”.

Tessa extrage informații din:

Confluence — documentații sincronizate automat, nocturn (ora 02:00)

Coda — specificații, documentații și documente de tip Specificație, Documentație, Documentații etc., dacă sunt încărcate și configurate în platformă.

Fișiere încărcate local — documente PDF, Word sau text atașate direct în chat


| Agent | Acțiuni | Cuvinte cheie de activare |
| --- | --- | --- |
| QnA | Răspunde la întrebări despre Charisma | Întrebări contextuale și detaliate pentru o mai ușoară identificare |
| PPM | Introducere pontaje în PPM | Intrare conversațională care conține informații structurate “pontează ore  pe proiect” |
| Chat | Conversație generală, Q&A | Orice solicitare generală |
| Summarizer | Rezumă texte lungi | "summarize", "summary" |
| Translator | Traduce texte/fișiere | "translate to", "translation" |
| DocuFlow | Generează PRD-uri, planuri, diagrame | "prd", "execution plan", "diagram" |
| Code Review | Analizează și îmbunătățește codul | "code review", "analyze code" |
| Jira Match | Citește o captură de ecran/fotografie a unei erori din Charisma și caută un tichet Jira similar. | Atașați o captură de ecran sau o fotografie a unui ecran Charisma cu mesaj de eroare |


Opțiunea de **File Search** rămâne separată și ne oferă posibilitatea să cerem unui agent informații în baza unei documentații încărcate local într-un agent personal sau al echipei.
