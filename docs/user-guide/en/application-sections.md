# Application Sections

The interface is organized in an intuitive way, with a side menu for navigation and a main area for interaction. On the left side is the conversation history organized chronologically, in the center is the chat area, and on the right are the additional configurations. 

![image](/help-images/en_0003.png)

All conversations remain saved and can be renamed if desired. Conversations are private for each user.

## Settings

The general application settings are accessed by clicking the username in the bottom-left corner of the screen.

### Balance – Token Limit

This tab displays the token limit for each user. The limit is 20,000 tokens, which renew daily at midnight. Unused tokens are carried over to the following day’s balance. A chat with a long history consumes more tokens than a new chat.

![image](/help-images/en_0004.png)

![image](/help-images/en_0005.png)

This tab allows management of documents and images uploaded to the platform by the user.

## Vertical menu

The vertical menu is positioned on the left side of the interface and displays the complete conversation history, organized chronologically. This section provides quick access to all previous chats and allows efficient management of these conversations.

![image](/help-images/en_0015.png)

To share, rename, copy, or delete a chat from the list, press the three dots and select the desired option.

![image](/help-images/en_0016.png)

**Features Available:**

**“Share” feature**

Allow sharing the page and its content with other team members. A unique link is generated that can be copied and distributed.

![image](/help-images/en_0017.png)

![image](/help-images/en_0018.png)

**“Rename”** feature

Changes the conversation name for quicker identification in the list. Useful for thematic organization of discussions.

![image](/help-images/en_0019.png)

**“Duplicate”** feature

Creates an exact copy of the chat screen, preserving the entire conversation history.

![image](/help-images/en_0020.png)

**“Archive”** feature

Archives the conversation, removing it from the main list without permanently deleting it. Archived chats remain accessible through: Settings → General → Archived chats

![image](/help-images/en_0021.png)

![image](/help-images/en_0022.png)

From the archive management screen, you can:

Filter – Quickly search through archived conversations

Unarchive – Restore a chat to the main list

Delete – Permanently delete from the archive

![image](/help-images/en_0023.png)

Feature **“Delete”** allows permanent  deletion of the selected chat screens.

![image](/help-images/en_0024.png)

## Vertical Menu Buttons

In the upper section of the vertical menu, several essential buttons are available for interface control and conversation management. Each button offers specific features that optimize the user experience.

### Close Sidebar – Hide Vertical Menu

Allows hiding the side menu to maximize workspace. Useful when you want to focus exclusively on the active conversation or when working on smaller screens.

![image](/help-images/en_0025.png)

### Agent Marketplace – Personal Agent Selection

From this button you can select agents created by each user and the agent for timesheets to PPM.

![image](/help-images/en_0026.png)

![image](/help-images/en_0027.png)

### Bookmarks – Quick Markers

An advanced functionality for saving keywords associated with important conversations. Bookmarks facilitate quick identification of specific chats in the vertical list, allowing easy resumption of discussions or quick access to previously obtained relevant information and answers.

![image](/help-images/en_0028.png)

Managing Bookmarks:

To bookmark a conversation: Add descriptive keywords

To delete all bookmarks: Press the button **"Clear all"**

![image](/help-images/en_0029.png)

### New Chat – Start a New Conversation

Opens a new chat window to start a separate conversation. Use this button to begin a new working session, keeping conversations organized.

![image](/help-images/en_0030.png)

### Workspace – Customized Workspaces

A functionality that allows the creation of dedicated work environments, with customized AI agents that respond exclusively based on specific uploaded documentation.

Use Cases:

Projects with specific clients that have proprietary documentation

Teams working on separate projects with dedicated resources

The need for contextualized responses based on specific materials

A workspace is created by clicking Select Workspace > Create Workspace.

![image](/help-images/en_0031.png)

**Workspace Settings:**

From the configuration menu, you can:

Manage team access – Adding or removing members

Rename the workspace – For easier identification

Add additional information – Descriptions, labels, notes

![image](/help-images/en_0032.png)

![image](/help-images/en_0033.png)

**Workspace Components:**

The workspace interface displays:

Active Conversations – All chats in that space

Defined agents – List of configured AI assistants

Members – Users with access to the workspace

Uploaded files – Documentation available for analysis

![image](/help-images/en_0034.png)

**Uploading Documentation:** To add new documentation, press the button **Upload** and select the desired files. Documents will be processed and integrated into the agent's knowledge base.

![image](/help-images/en_0035.png)

**Assistant Selector – Select an Assistant**

Allow changing the active assistant in the current conversation. Each option offers various capabilities:

Assistant - Answers questions based on documentation uploaded in Confluence/Coda, offers a range of functionalities: translations, documentation and diagram generation, code review.

File Search - Answers questions based on documentation uploaded in the chat.

My Agents – Provides access to agents created by the user.

## Feedback

Tessa includes a built-in Feedback function that lets you report a bug, suggest an improvement, or share any other comment about the application directly from the interface, without leaving your current conversation. Feedback can include a short message and, optionally, screenshots or photos illustrating the issue.

![image](/help-images/en_0037.png)

### Submitting Feedback

A round blue Feedback button is available in the bottom-right corner of the screen, on every page except the Feedback page itself. Click it to open the Feedback form.

To submit feedback:

Click the Feedback button in the bottom-right corner of the screen.

Select a Category: Suggestion, Bug, or Other.

Type your Message (up to 5000 characters).

Optionally, click Attach image to add up to 3 screenshots or photos illustrating the issue.

Click Submit Feedback.

![image](/help-images/en_0038.png)

**Note: Feedback is linked to your user account, but it is not tied to a specific conversation, you can send feedback about the application at any time, from any screen.**

### Feedback Review (Administrators)

Administrators can review all feedback submitted by users directly on the same page, below the submission form.

![image](/help-images/en_0039.png)

Filter the list using the All categories or All statuses filters.

Each entry shows the category, the author, the submission date, the message, and any attached images.

Click Mark as reviewed to change the status of an entry once it has been addressed; the button switches back to Mark as new if needed.
