## PPM Agent Troubleshooting

Error 1 – The agent is not running correctly:  "Cancelled" appears constantly in the chat

![image](/help-images/en_0104.png)

**Suggestion:** *Use the refresh button or open another chat to restart the session.*

### Error 2 – The agent does not respond correctly

Check if the "Ran add_timesheet_entry" function has run — it should be visible in the chat, not just in "Thoughts".

![image](/help-images/en_0105.png)

![image](/help-images/en_0106.png)

**Suggestion: Check if the "Ran add_timesheet_entry" function has run. If the result is not visible, press the refresh button in the chat.**

### Error 3 – The agent not send all written notes; only partially sent to PPM

![image](/help-images/en_0107.png)

**Suggestion: Check if the "Ran add_timesheet_entry" function has run. If the result is not visible, press the refresh button in the chat.**

### Error 4 – The agent confirms that data was sent to PPM, but it does not appear in the application

![image](/help-images/en_0108.png)

**Suggestion: Press the refresh button in the chat to update the data and verify the recording.**
